Personnaliser le montage HOOK · CADRAGE · AUDIO
L’analyse Whisper pour le hook est activée par défaut, même sans sous-titres. Elle ajoute le temps de transcription locale ; désactive-la pour accélérer le rendu. Sans moteur ou modèle disponible, le Short continue sans hook automatique. Les sous-titres restent facultatifs et désactivés par défaut. Ils nécessitent whisper.cpp et le modèle multilingue local large-v3-turbo (~1,6 Go). Whisper alimente aussi le hook automatique. Sans transcription exploitable ni note de contexte, aucun hook générique n'est inventé ; tu peux saisir un hook manuel. Filtrage vocal local en bêta : le filtre strict est utilisé pour les sous-titres. Pour le hook seul, le Studio réutilise ce filtre s’il est déjà installé, mais ne déclenche pas son installation à la demande afin de préserver la rapidité ; sans filtre, la transcription peut inclure des dialogues du jeu. La première utilisation des sous-titres peut installer le filtre local et prendre plus de temps.
