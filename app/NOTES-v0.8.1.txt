GTA Ranked Studio v0.8.1

Audit et assainissement du dépôt :
- Synchronisation stricte de VERSION.txt, app/VERSION.txt, pyproject.toml et config.yaml.default.
- Suppression des anciens instantanés de documentation et de notes sous app/. La documentation canonique reste à la racine dans docs/ et est injectée au moment du packaging.
- Suppression du scaffold Best Of et du fichier inbox/urls.txt, non reliés à un moteur fonctionnel.
- Suppression des dépendances et répertoires inutilisés, sans retirer le flux Shorts.

Installation plus légère :
- Séparation des dépendances runtime et des outils de développement.
- L'installation utilisateur n'installe plus pytest/httpx/httpx2 et n'exécute plus toute la suite de tests.
- L'installateur exécute un contrôle runtime ciblé, pip check et le diagnostic local.
- Les suites Linux et Windows restent obligatoires avant publication.
- Ruff 0.17.6 contrôle le code Python et pip-audit 2.10.1 examine les dépendances runtime en CI uniquement.

Packaging et sécurité :
- Le constructeur de ZIP exclut les tests, les outils binaires locaux, les configurations privées, les secrets, les bases, les médias, les modèles et fichiers temporaires.
- Les liens symboliques ne sont pas inclus.
- Le contrôle d'intégrité commun vérifie la racine, les chemins du ZIP, les fichiers requis, les données interdites et le SHA-256.
- Un parseur PowerShell dédié vérifie les scripts d'installation et de mise à jour. Le résultat d'exécution Windows doit confirmer cette vérification avant publication.

Maintenance :
- Actions GitHub mises à niveau, concurrence CI réduisant les audits redondants.
- Dependabot mensuel activé pour les dépendances Python et les workflows GitHub Actions.
- La migration d'anciennes installations reste disponible.

La validation matérielle AMD AMF/Vulkan doit toujours être effectuée sur la RX 9060 XT réelle.
